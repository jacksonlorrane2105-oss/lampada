# Minha primeira página no ar 💡

Projeto simples de uma página web interativa feita com HTML, CSS e JavaScript.

Ao clicar no botão, a lâmpada muda de estado e o fundo da página muda de cor.

## ✨ Funcionalidades

- 🌑 Lâmpada apagada ao carregar a página
- 💡 Ligar e desligar a lâmpada
- 🔘 Alternar o texto do botão entre **Ligar** e **Desligar**
- 🎨 Alterar as cores da página
- 💬 Exibir mensagens conforme o estado da luz

## 📂 Arquivos

```text
index.html  -> Estrutura da página
estilo.css  -> Estilos e cores
script.js   -> Interação da lâmpada
README.md   -> Documentação do projeto
```

## ▶️ Como usar

1. Abra a pasta do projeto.
2. Abra o arquivo `index.html` no navegador.
3. Clique no botão para ligar ou desligar a lâmpada.
